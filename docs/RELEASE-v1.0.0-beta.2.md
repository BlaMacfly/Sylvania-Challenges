## Les 10 défis inclus

1. Hardcore
2. Semi-Hardcore
3. Auto-artisanat / Self Crafted
4. Qualité d'objet limitée
5. XP lente
6. XP très lente
7. XP de quêtes uniquement
8. Iron Man
9. **Martyr**, ajout Sylvania
10. **Survival**, ajout Sylvania

Ces dix défis sont répartis entre les deux dossiers de code `mod-challenge-modes` et `mod-survival`. Ils sont tous présents dans le pack complet. L'addon est également fourni dans `Interface/AddOns/SylvaniaSurvival/`, prêt à copier dans le client WotLK 12340.

Cette publication clarifie le catalogue et les téléchargements et ajoute les crédits de BlaMacfly. Les sources serveur et l'addon restent identiques à la version installée sur Sylvania R1. Les notices du module d'origine [ZhengPeiRu21/mod-challenge-modes](https://github.com/ZhengPeiRu21/mod-challenge-modes) sont conservées.

**Version de test :** Survival reste à valider en jeu. Le moteur et l'addon disposent de 55 contrôles automatisés ; `/survivalui test` permet un aperçu sans modifier le personnage.

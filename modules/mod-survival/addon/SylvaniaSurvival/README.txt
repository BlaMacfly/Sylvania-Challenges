Sylvania Survival 0.2.0 — WotLK 3.3.5a (12340)

Trois jauges : Nourriture, Hydratation, Froid.
Les icônes sous les jauges indiquent les malus confirmés par le serveur.
Survolez les jauges et les malus pour lire leur fonctionnement.
Le cadre est déplaçable avec la souris ; sa position est conservée par personnage.

Commandes :
/survivalui test       Aperçu pendant 60 secondes, sans modifier le personnage
/survivalui stop       Fermer l’aperçu
/survivalui lock       Verrouiller la position
/survivalui unlock     Déverrouiller la position
/survivalui scale 110  Régler la taille, de 80 à 160 %
/survivalui reset      Restaurer la position et la taille

Pour une première installation, quitter complètement WoW puis le relancer.
Vérifier Sylvania Survival dans le bouton AddOns à la sélection des personnages.
Les jauges réelles apparaissent uniquement sur un personnage avec le défi actif.
L’addon conserve la compatibilité avec l’ancien serveur et indique alors son ancienne version.

Version de test. Publication sur le site après validation en jeu.

# Sylvania Survival 0.2

Module serveur complémentaire de Sylvania Challenges pour WotLK 3.3.5a.

- Nourriture vide : −50 % aux cinq caractéristiques principales.
- Hydratation vide : plafond de vie progressif jusqu'à 1 %.
- Froid : exposition, abris et feux de cuisine.
- Addon 0.2.0 : jauges, icônes et malus confirmés par le serveur.

Ce dossier doit être installé à côté de `mod-challenge-modes`. L'intégration de ce dépôt est déjà effectuée ; ne réappliquez pas les patchs historiques.

Voir le [guide d'installation](../../docs/INSTALLATION.md), les [vérifications](../../docs/VALIDATION.md) et le [README du projet](../../README.md).

Version de test.

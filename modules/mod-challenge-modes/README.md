# Défis Sylvania

Version installée du module Challenge Modes, avec les huit défis historiques et les ajouts **Martyr** et **Survival**. Ce module dépend du dossier voisin `mod-survival` fourni par ce dépôt.

Voir le [README du projet](../../README.md) et le [guide d'installation](../../docs/INSTALLATION.md). Le [README historique](../../docs/UPSTREAM_README.md) est conservé à titre d'attribution ; le menu Sylvania actuel impose le niveau 1.

Les sources C++ et configurations distribuées de ce dossier conservent les octets exportés du serveur. Les deux SQL de dépendances Sylvania sont ajoutés pour permettre une nouvelle installation sans données de compte ou de personnage.
